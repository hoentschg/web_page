# QUIMERA - Plataforma Web Corporativa

Sitio web oficial de **Quimera**, inspirado en la estética inmersiva de [Lusion.co](https://lusion.co/), diseñado para transmitir autoridad, solidez tecnológica y vanguardia en ciberseguridad, desarrollo a medida y soporte de misión crítica.

---

## 🛡️ Los Tres Pilares de Quimera

1. **Seguridad de la Información & Zero-Trust**:
   - Blindaje de datos empresariales para evitar filtraciones, pérdidas o secuestros (Ransomware).
   - Backups inmutables WORM, cifrado AES-256 en reposo y tránsito, prevención de fuga de datos (DLP).
   - Auditorías y Ethical Hacking continuo.

2. **Desarrollo de Software a Medida**:
   - Aplicaciones y plataformas construidas desde cero para cualquier industria o sector (Fintech, Salud, Retail, Logística, Minería, etc.).
   - Metodología DevSecOps: seguridad probada desde la primera línea de código.
   - Propiedad intelectual 100% del cliente, sin licenciamientos cautivos.

3. **Soporte Técnico Especializado Corporativo**:
   - Centro de Operaciones de Seguridad (SOC) y monitoreo 24/7/365.
   - SLA crítico de resolución menor a 15 minutos.
   - Continuidad de negocio y planes de Disaster Recovery.

## 🚀 Cómo Iniciar la Web (Puerto 5000)

El servidor está configurado para ejecutarse en el puerto **5000**:

```bash
npm start
```
o simplemente:
```bash
node server.js
```

Abre en tu navegador:
👉 **[http://localhost:5000](http://localhost:5000)**

## 🌟 Características Interactivas Destacadas

- **Núcleo 3D Quimera (Three.js)**: Polyhedron cuántico interactivo con anillos orbitales, constelación de nodos que dibujan enlaces dinámicos por proximidad y nebulosa de partículas que responden al mouse.
- **Selector de Modos 3D**: Permite alternar la geometría y los colores de la escena entre *Ciberseguridad*, *Software a Medida*, *Soporte 24/7* y *Nexus Quimera*.
- **Sintetizador de Audio Sci-Fi (Web Audio API)**: Botón de sonido en el header (homenaje a Lusion) con visualizador en vivo de frecuencias y feedback acústico sutil en interacciones.
- **Simulador de Ciberataques & Neutralización**: Consola interactiva para simular Ransomware, Fuga de Datos (DLP), DDoS (850 Gbps) y exploits Zero-Day con logs en vivo y barra de defensa perimetral.
- **Calculadora de Arquitectura**: Diagnóstico interactivo según sector, tamaño de empresa y prioridad.
- **Cursor Magnético Fluido**: Puntero personalizado con seguimiento suavizado (*lerp*).
- **Modal de Protocolo Cifrado**: Formulario de contacto con animación de cifrado AES-256 y respuesta instantánea.
